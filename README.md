# 网格策略 App

独立 Flutter 工程，用于 iOS 和 Android。当前首版已迁移网页网格策略面板的核心能力：

- A 股标的切换与新增
- 公开行情刷新、日 K 和 MA20
- 持仓、成本价和一键粘贴录入
- 网格买卖价位计算
- 仓位建议器
- 买卖成交记录、策略日志和每日快照
- 使用 `shared_preferences` 保存本地数据
- 全市场换手率筛选、收盘量价确认与次日观察名单复核

## 开发运行

```bash
cd grid_strategy_app
flutter pub get
flutter run
```

## 构建

```bash
flutter build apk --debug
flutter build apk --release
flutter build ios --no-codesign
```

## 行情说明

原项目的 `stock-sdk` 是 JavaScript/npm 依赖，不能直接被 Dart 原生工程引用。本 App 使用 Dart `http` 适配同类公开行情接口，账户、日志和快照仍保存在设备本地。行情接口是公开市场数据，存在延迟和网络失败可能，不应作为唯一下单依据。

## 换手率筛选操作

1. 在操盘台右上角点击统计图标，进入“换手率选股”。
2. 设置小盘、中盘、大盘换手率阈值、近 20 日均量倍数和核验数量，点击“开始全市场扫描”。建议收盘后运行，以便确认完整日 K。
3. 对显示“次日买入候选”的标的点击“加入观察”。
4. 下一交易日 09:45 后，点击观察名单的“刷新信号”。页面按昨收、昨日 MA5/MA10、分时均价和日内低点反弹幅度逐项展示结果。
5. 每次刷新只请求一次快照，不会持续订阅；名单保存在设备本地。请求失败时可稍后手动重试。

“次日条件满足（候选）”只是规则筛选结果，不是买入指令，不会自动下单。公开行情可能延迟，勿将单一技术条件作为投资决策依据。
